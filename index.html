Machine Learning Model Comparison on the Wisconsin Breast Cancer Dataset

This project focuses on improving the early detection of breast cancer by classifying tumors as malignant or benign using various machine learning algorithms. We implemented Logistic Regression, Decision Tree, Support Vector Machine (SVM), Bagging Logistic Regression, XGBoost, AdaBoost SVM, and a Stacked Ensemble model on the Breast Cancer Wisconsin (Diagnostic) dataset. The Stacked Ensemble, combining predictions from all other models, achieved the highest accuracy of 99.1%. This demonstrates the effectiveness of ensemble techniques, especially stacking, in enhancing predictive performance for critical detection tasks.
